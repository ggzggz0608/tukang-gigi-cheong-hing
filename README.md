# Tukang Gigi Cheong Hing

Laman web kedai — https://gigibook.online

Kedai gigi palsu tradisional di Kota Bharu, Kelantan.
Ditubuhkan 1950, kini generasi keempat.

Laman ini statik sepenuhnya dan **tiada kaitan dengan mana-mana sistem dalaman** —
tiada API, tiada log masuk, tiada data pelanggan.

Sumber (build script + kandungan): repositori peribadi `gigibook`, folder `landing/`.
